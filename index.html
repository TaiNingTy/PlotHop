How to use PlotHop

  1. Drag the search circle or adjust its radius. Select a purple parcel to open Walk Coverage.
  2. Switch to Station Fit to test station footprints, parcel insets, and building retention.
  3. In Walk Coverage, bright purple lines show reachable paths, pale purple fills show connected blocks, and the cyan diamond marks the modeled starting point.

The dashed circle is the fixed ½-mi walk reference. Metrics marked “Needs verification” require more evidence.

Walk coverage review

Resident estimates use 2020–2024 ACS B01003 block group data. Job estimates use 2023 LODES WAC workplace counts at the census block level.

Resident estimates use the share of each ACS block group’s land inside the search circle, with mapped TIGER/Line water removed from both the overlap and the block group area. A fully water-covered circle within data coverage returns zero estimated residents. Job estimates use the share of each workplace census block’s full area inside the circle. Mapped water is not removed from the job-area calculation. Results need verification where the circle extends beyond data coverage. Gray parcels provide map context. Purple highlights show initial footprint candidates plus the B/C comparison sites. Each parcel record counts once if its geometry intersects or just touches the search circle. Only the part inside the circle is highlighted. Multiple records with the same parcel group can count separately. Regional candidates use the part of each parcel outside mapped TIGER/Line water. The initial screen applies a 1.64 ft test inset to that land and excludes mapped buildings. Engineering feasibility still needs verification.

Search area review

Historical pedestrian counts come from a TPO field survey on Tuesdays in May 2016, 4–6 p.m. local time. Totals cover only recorded crossings inside the search area. Recent pedestrian and time-of-day transit boarding and alighting counts need verification.

Regional station fit uses parcel land outside mapped TIGER/Line water. Station fit tests a 49.2 ft wide rectangle. Baseline and growth assume 120 and 210 vehicle service events per hour, respectively, at 45 events per berth per hour. Insets are sensitivity inputs. The compact 93.5 ft case uses a dimension from a platform detail. For site C, the upper bound on turning depth subtracts station length from the available north–south depth. Guideway width, transitions and vehicle swept path still need verification. Keeping existing buildings excludes mapped county building footprints. Actual setbacks, parking, utilities, construction clearances and guideway connections still need verification.

The fixed ½-mi reference circle defines the analysis area. Within it, modeled reachability uses a 15-minute network budget, an assumed speed of 2.68 mph, a proxy entrance, and a 30-second wait at each tagged signalized crossing. At a map scale of 500 ft or closer, yellow rings mark mapped crossing endpoints that connect to a pedestrian path. Landings within 5 ft of a basemap road centerline are hidden pending verification. Crossing-point counts use the original records. The dashed access link is provisional. Supplemental links use county sidewalk inventory and public shared-use paths with a 114.8 ft connection limit. Entrances, crossings and accessibility still need verification. U.S. DOT uses a ½-mi pedestrian catchment benchmark for certain transit eligibility analyses. U.S. DOT TOD guidance

For regional candidates, the denominator is all 2020 census blocks with a representative land point inside the fixed reference circle, including blocks with unverified access. The numerator counts blocks whose representative point can reach a mapped path within 114.8 ft without crossing mapped roads or water and whose total walk, including that connection, is within 15 minutes. Residents are allocated by ACS block group land area and modeled on an approximately 66 ft grid. Where no grid point samples an intersected portion of a block group, those residents need verification.
